### Vysvětlení každého řádku diffu

- `freeOfferExpirationTime` (delete): read-only vlastnost přiřazená Azure při vytvoření plánu (12měsíční
  free-tier okno), není součástí zapisovatelného schématu `Microsoft.Web/serverfarms`. Šablona ji
  nemůže ani nechce nastavovat — neškodný artefakt what-if.
- `sku.tier` (Noeffect `x`): hodnota se shoduje (`Basic`), what-if ji jen informativně zobrazuje.
- `siteConfig.ftpsState/minTlsVersion/webSocketsEnabled` (`+`): hodnoty **shodné** se skutečným
  stavem zjištěným v inventuře (Disabled/1.2/true) — what-if je značí jako "Create", protože
  Azure Resource Graph model, ze kterého what-if čte baseline, tyto tři vlastnosti nevrací jako
  explicitně nastavené, ačkoli efektivní hodnota je stejná. Idempotentní, bez rizika.
- `localMySqlEnabled: false`, `netFrameworkVersion: v4.6` (`+`): defaultní hodnoty Azure App Service
  pro linuxové `.NET` runtime; nejsou v našem repozitáři relevantní a jejich nastavení nemá efekt na
  Linux/.NET 10 web app (jde o pole platná primárně pro Windows/.NET Framework stack).
- Static Web App `deploymentAuthPolicy`, `provider`, `stableInboundIP`, `trafficSplitting` (delete):
  všechny čtyři jsou computed/systémem spravované vlastnosti `Microsoft.Web/staticSites`, které
  Bicep u této API verze nelze nastavit v `properties` bloku vůbec (nejsou to zapisovatelné vstupní
  parametry). Toto je zdokumentovaná what-if noise pro Static Web Apps (viz poznámka nástroje
  "may contain false positive predictions"). Žádná z nich neřídí data, autorizaci nasazení SWA CLI
  ani traffic split hodnotu samu o sobě mizí nikam — je to jen chybějící echo v diffu.
- Žádný řádek nenavrhuje smazání DB/storage dat, druhou instanci, změnu hostingu (App Service →
  jiná služba) ani smazání app settings kolekce. Akceptační kritérium I01 splněno.

Status: **PASS** (what-if proveden, žádný nejasný destruktivní diff). Runtime funkčnost (skutečné
