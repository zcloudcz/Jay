## 1. TCP connect probe

Příkaz: `Test-NetConnection -ComputerName 187.127.83.154 -Port 5544`
Očekáváno: TCP handshake úspěšný (samotné otevření portu, ne DB autentizace).
Skutečný výsledek: **FAIL** — `TcpTestSucceeded: False`, spojení vypršelo (timeout), ICMP ping také
timeout. Nelze odlišit, zda je port firewallován jen pro neznámé zdrojové IP (toto prostředí
zjevně není v allow-listu serveru ani ve výčtu App Service outbound IP z `beta-inventory.md`),
zda je port skutečně zavřený, nebo zda je server dočasně nedostupný ze sítě tohoto agenta.

Pro srovnání: stejný postup vůči TURN portem `3478` na stejném serveru **prošel** (viz
`docs/ops/evidence/I03.md`), takže server jako celek je ze sítě tohoto agenta dosažitelný — problém
je specifický pro port `5544` nebo pro DB firewall pravidla.
