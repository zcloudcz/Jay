3. Co nikdy nemáme

  • Obsah vašich zpráv, hovorů, souborů, názvů skupin a záloh. Šifruje se na vašem zařízení klíči, které ho nikdy neopustí (protokol Signal: X3DH a Double Ratchet).
  • Váš adresář. Kontakty se přidávají jen QR kódem nebo pozvánkou.

4. Zpracovatelé

  • Microsoft Azure (Microsoft Ireland Operations Ltd.), region Západní Evropa: API server, úložiště zašifrovaných souborů a záloh a webová aplikace.
  • Hostinger: virtuální server s databází PostgreSQL.
  • Cloudflare: přenosový server TURN pro hovory, když přímé spojení není možné. Hovory zůstávají koncově šifrované (DTLS-SRTP), server vidí jen IP adresy a objem dat.
  • Google Firebase Cloud Messaging (Android) a Apple Push Notification service (iOS): doručení upozornění bez obsahu.
  • Notifikační služba vašeho prohlížeče (např. Mozilla, Google, Apple nebo Microsoft), pokud ve webové aplikaci povolíte upozornění.

Někteří z těchto poskytovatelů mohou zpracovávat data i mimo EU (např. v USA). Takový přenos se opírá o rámec EU-USA pro ochranu osobních údajů nebo o standardní smluvní doložky Evropské komise.

5. Vaše práva

Podle GDPR máte právo na přístup, opravu, výmaz, omezení zpracování, přenositelnost a právo vznést námitku, a také právo podat stížnost u Úřadu pro ochranu osobních údajů (uoou.gov.cz).

  • Přístup a přenositelnost: v aplikaci Nastavení > Soukromí > Exportovat moje data stáhne vše, co o vás server má, ve formátu JSON.
  • Výmaz: Nastavení > Účet > Smazat účet, další možnosti viz Smazání účtu.
  • S čímkoli dalším pište na info@zcloud.cz a uveďte svůj identifikátor. Odpovíme do jednoho měsíce.

6. Děti

Jay není určen dětem mladším 15 let. Pokud je vám méně, nepoužívejte ho bez souhlasu rodiče nebo zákonného zástupce.

7. Zabezpečení

Kromě koncového šifrování chrání přenos TLS, hesla se ukládají jako otisk Argon2id a místní databáze ve vašem zařízení je šifrovaná. Známá omezení šifrování aplikace otevřeně popisuje. Bezpečnostní chyby: security.txt.
